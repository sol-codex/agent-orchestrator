# Hub A1 graph contract digest

`backend/internal/domain/HubGraphContractDigest` calculates a planning-field digest for Hub's A1 provenance binding. It is read-only and is **not** connected to AO's import API or scheduler. The Hub TypeScript implementation uses the same domain separator, canonical key order, and fixture digest. The fixture covers the complete immutable projection; arrays retain order and empty optional slices become `[]`. Go rejects actual U+2028 and U+2029 characters because its JSON encoder differs from JavaScript for those characters; literal `\u2028` and `\u2029` text remains valid. Go also rejects invalid UTF-8, while Hub rejects unpaired UTF-16 surrogates.

This digest is evidence that an AO `ExecutionGraph` has the same declared planning fields as Hub's prepared graph. It grants no dispatch authority. AO's existing graph POST still wakes the scheduler, and Hub-origin graphs must wait for a separate inert prepare/activate contract and explicit owner dispatch authorization. AO's current worker prompt uses graph task content; preserving Hub's goal-ignorant `PieceHandoff` firewall is a later integration requirement before a Hub-origin task may run.
